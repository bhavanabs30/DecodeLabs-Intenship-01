# 🧠 DecodeLabs To-Do Manager

A simple **Python command-line To-Do List app** built as part of the **DecodeLabs Industrial Training Kit — Project 1 (Batch 2026)**.

This project is the "logic phase" of the internship — focused on mastering **data management** by storing multiple items in a single variable before moving on to databases. Starting from the classic `my_tasks = []`, it grows into a small backend engine that follows the **IPO Model** (Input → Process → Output).

---

## ✨ Features

- ➕ Add a task with priority & due date
- 📋 View all tasks with numbering
- ✏️ Update an existing task
- 🗑️ Delete a task by ID
- ✅ Toggle task as complete / pending
- 🔍 Search tasks by keyword
- 🎯 Filter tasks (pending / completed / overdue)
- 📊 Stats dashboard with progress bar
- ↩️ Undo last action
- 👥 Multi-user support
- 💾 Save & load tasks with JSON (persistence)
- 🎨 Colored terminal output
- ⚡ Graceful exit with auto-save
